# IAIRS ? The Anomaly

The public landing follows one clearly labeled illustrative SSH incident through six acts: Control, Fracture, Detection, Verdict, Response, and Restoration. The same vermilion signal moves from editorial type into liquid geometry, a connected evidence field, the calculated risk, an existing response policy, and the console grid.

## Audit and boundaries

## Implementation plan and architecture

1. Establish an ivory editorial grid, three locally served font families, semantic headings, native chapter anchors, skip, and direct console access.
2. Fracture character-split, three-slice typography with scroll-driven transforms and a seeded SVG displacement filter. Morph sampled glyph points into a liquid silhouette.
3. Render a signed-distance liquid extrusion of the actual headline in one persistent WebGL2 context. The same signal coordinate drives its center and the dark liquid aperture. Move the same deterministic particles into a projected evidence network.
4. Converge those particles into the actual risk number; show verified contributions from the existing engine and a keyboard-accessible evidence slider.
5. Route the response pulse along the actual selected SVG path, then align particles and rules into the real console preview. Enter the existing `#console/overview` route.
6. Inspect rendered desktop/mobile compositions; test forward/reverse scroll, preferences, failures, and the existing application; publish to the existing Site with its audience unchanged.

The current source is isolated in:

- `src/anomaly.js`: six semantic scenes, sliced characters, vector fallback, chapter navigation, evidence and response controls, accurate console capture.
- `src/anomaly-director.js`: a GSAP master timeline driven by ScrollTrigger, shared 0?5 narrative coordinate, measured type and response targets, bounded velocity/pointer influence, accessible scene state, cleanup.

- `src/signal-particles.js`: 4,096 desktop / 1,024 mobile GPU identities, sampled opening and fracture glyph targets, liquid-band coordinates, a full-frustum connected network, risk glyphs, flowing measured response paths, and real console panel boundaries. Shares the liquid context.
- `src/signal-field.js`: stable particle identities and deterministic glyph ? liquid ? network ? score ? policy path ? console-grid morph targets, projected wireframe evidence volume, construction guides, selected-path pulse.
- `src/anomaly.css`, `src/anomaly-editorial.css`: scoped editorial layout, responsive compositions, warm material tokens, grain, halftone, selective glass, focus states, and console view transition.

Earlier cinematic/artwork implementations remain in the checkout as historical source, but are not imported by the current landing. ## Narrative and technical truth

`makeJourney` calls the unchanged `evaluateEvents` engine in memory. Forty failed SSH logins in 3.3 seconds exceed the existing threshold of 20 within 60 seconds and yield **84/100, Critical**.

| Existing factor | Contribution | Maximum |
| --- | ---: | ---: |
| Attack type | 36 | 40 |
| Event frequency | 30 | 30 |
| Host impact | 9 | 20 |
| Time window | 9 | 10 |

The slider explores 10?80 failures: 10 is below detection threshold; 20 produces risk 70 and simulated IP block; 40 produces risk 84 and simulated host isolation. The response branches retain Low 0?25, Medium 26?50, High 51?75, and Critical 76?100. The original engine implements log, alert, simulated IP block, and simulated host isolation. The interactive landing policy explorer additionally visualizes a simulated administrator notification for Critical severity. This is explicitly a visual policy demonstration: it neither contacts an administrator nor changes console incident records. The original console engine and its action strings are unchanged.

Particle samples visualize the single illustrative case; they are not additional network events. Exploration does not add records to the console dataset. No live traffic or real containment is claimed.

The final reveal is the actual running console, not a screenshot. Its panel boundaries become GPU morph targets, and an iframe-local presentation layer reconstructs the real panels before the viewport expands. The operational application source and styling are unchanged. The CTA enters the top-level console with View Transitions where supported and a native hash link elsewhere.

## Accessibility, fallbacks, and performance

Native scrolling is retained without wheel/touch interception or scroll trapping. CSS pins the single stage. Every major transformation resolves from position and reverses. Ambient movement and bounded velocity are secondary.

Inactive scenes are inert and excluded from assistive technology. Split visual letters have accessible heading equivalents. Chapter links, inspector, slider, replay, skip, and console links are keyboard operable with visible focus. Escape closes inspection. OS reduced motion and the console motion preference remove distortion, ambient movement, magnetic behavior, and animated navigation. No audio is present.

The texture-free shader caps DPR at 1.25 desktop / 1 phone, uses 48 bounded distance steps, and caps ambient drawing at 36 / 24 FPS. Sustained slow frames lower rendering resolution. The Canvas layer uses 4,096 desktop / 1,024 phone particle identities and capped DPR. Hidden tabs pause rendering. Route cleanup releases ScrollTrigger, GSAP, listeners, observers, animation frames, WebGL buffers/programs, and contexts.

Without WebGL or after context loss, the vector liquid fallback preserves the narrative. Without Canvas, semantic type, scoring controls, navigation, and the accurate console preview remain available.

## Living incident revision

The torus/loop was removed from both the surface shader and particle targets. `signal-distance.js` converts a rasterized mask of the actual headline into a signed distance field. The shader extrudes, cracks, shears, and fluidly deforms those glyphs; the particle shader uses the same forward deformation before expanding into the network. The opening runs a seamless ten-second secondary cycle of letter displacement, depth, material color, directional light, grid movement, and autonomous anomaly motion; its strength blends away with scroll. Hover/click evidence inspection focuses the same anomaly region. Severity buttons preview all four response branches entirely in memory.

## Sculptural material direction

The latest reference establishes broad reflective silver and champagne surfaces with translucent depth as the main form. `signal-ribbons.js` adds five tessellated open ribbons with analytic normals, shaped cross-sections, reflected area lights, Fresnel glass, procedural transmission, and depth-tested opaque/transparent passes. They emerge from actual headline-stroke coordinates and share `signal-ribbon-shape.js` with the GPU particle targets and Canvas connections. Evidence therefore lives on the same surfaces. Those surfaces disintegrate into the score, become selected response rails, and resolve into measured console panel boundaries. The desktop surface uses 240 longitudinal segments; mobile uses 128. No torus, premade model, or background animation asset is used.
